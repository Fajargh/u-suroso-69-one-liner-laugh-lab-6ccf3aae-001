An entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on make.fun.

## The line

The excuse a GPS gives after getting you lost:

> In my defence, 'turn left in 200 metres' was correct — I just never said which century's map I was using.

## How it works

`main.py` writes that single line to `/output/entry.txt` and validates it
first: 1–200 characters, a single line, not blank. Run it with:

```sh
python3 main.py
```
